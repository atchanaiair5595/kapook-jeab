# กระปุกเจี๊ยบ: วิธีเชื่อม Google Sheet

ทำบนคอมพิวเตอร์ ใช้เวลาประมาณ 20 นาที ทำครั้งเดียว

## ส่วนที่ 1: สร้าง Google Sheet และวางโค้ด

1. เปิด sheets.google.com ด้วยบัญชี Google ที่จะใช้เก็บข้อมูล แล้วกด **ว่าง (Blank)**
2. ตั้งชื่อชีตมุมซ้ายบน เช่น `บัญชีกระปุกเจี๊ยบ`
3. เมนู **ส่วนขยาย (Extensions) → Apps Script**
4. ในหน้าที่เปิดขึ้น ลบโค้ดเดิม (`function myFunction…`) ออกให้หมด
5. เปิดไฟล์ `Code-ใส่ใน-AppsScript.txt` กด Ctrl+A แล้ว Ctrl+C ไปวางในหน้า Apps Script (Ctrl+V)
6. กดรูปแผ่นดิสก์ (บันทึก) หรือ Ctrl+S

## ส่วนที่ 2: ตั้งค่าครั้งแรก และรับรหัสลับ

1. กลับไปที่แท็บ Google Sheet แล้วกด F5 (รีเฟรช)
2. รอสักครู่ จะมีเมนู **🐣 กระปุกเจี๊ยบ** ขึ้นด้านบน → กด **ตั้งค่าครั้งแรก / ดูรหัสลับ**
3. Google จะขออนุญาต:
   - กด **ดำเนินการต่อ (Continue)** แล้วเลือกบัญชีของคุณ
   - ถ้าขึ้นว่า “Google ยังไม่ได้ยืนยันแอปนี้” ให้กด **ขั้นสูง (Advanced)** → **ไปที่ … (ไม่ปลอดภัย)**
     (ขึ้นแบบนี้เพราะเป็นโค้ดที่คุณใส่เอง ไม่ได้ผ่านการรับรองจาก Google)
   - กด **อนุญาต (Allow)**
4. กดเมนู **ตั้งค่าครั้งแรก / ดูรหัสลับ** อีกครั้ง จะมีหน้าต่างแสดงรหัสลับขึ้นต้นด้วย `kj-` → กด **คัดลอกรหัส** แล้วเก็บไว้

## ส่วนที่ 3: เปิดเป็น Web app

1. กลับไปหน้า Apps Script → ปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง ⚙️ ข้าง “เลือกประเภท” → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - คำอธิบาย: `กระปุกเจี๊ยบ`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
4. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป** (ขึ้นต้น `https://script.google.com/macros/s/` ลงท้าย `/exec`)

“ทุกคน” หมายถึงลิงก์นี้รับคำขอจากแอปได้ แต่จะอ่านหรือเขียนข้อมูลได้ต้องมีรหัสลับที่ตรงกันเท่านั้น

## ส่วนที่ 4: อัปโหลดแอปขึ้น GitHub

1. แตกไฟล์ `kapook-jeab-app-v2.zip` จะได้ 7 ไฟล์
2. ใน GitHub เปิด repository ของแอปเดิม (หรือสร้างใหม่ชื่อ `kapook-jeab` แบบ Public)
3. กด **Add file → Upload files** ลากทั้ง 7 ไฟล์ไปวางทับ → **Commit changes**
4. ถ้าเป็น repository ใหม่: **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save แล้วรอ 1–2 นาที
5. ห้ามอัปโหลดไฟล์โค้ด Apps Script ขึ้น GitHub

## ส่วนที่ 5: เชื่อมในแอป

1. เปิดแอปในมือถือ (ถ้าติดตั้งไว้แล้ว ปิดแล้วเปิดใหม่ 1–2 ครั้งให้ได้เวอร์ชันใหม่)
2. **เมนู → Google Sheet** วางลิงก์ Web app และรหัสลับ → กด **ทดสอบและเชื่อมต่อ**
3. ป้ายมุมบนขวาขึ้น **✅ ซิงก์กับ Sheet แล้ว** แปลว่าเสร็จ
4. เปิด Google Sheet จะเห็นแท็บ: รายการบัญชี, สรุปรายเดือน, กระเป๋าเงิน, รายชื่อคน, ยอดค้างจ่าย, ประวัติจ่ายเงิน, ตารางออม, หนี้

## ป้ายมุมบนขวาบอกอะไร

| ป้าย | ความหมาย |
|---|---|
| ✅ ซิงก์กับ Sheet แล้ว | ข้อมูลในมือถือกับชีตตรงกัน |
| ⏳ รอส่ง 2 | มีรายการที่ยังไม่ขึ้นชีต เดี๋ยวแอปส่งเอง |
| 📴 ออฟไลน์ · รอส่ง 2 | ไม่มีเน็ต บันทึกต่อได้ตามปกติ มีเน็ตแล้วจะส่งเอง |
| ⚠️ ซิงก์ไม่สำเร็จ | แตะที่ป้ายเพื่อดูสาเหตุ |

## ข้อควรรู้

- แก้ข้อมูลในแอปเท่านั้น แท็บในชีตแอปจะเขียนใหม่ทุกครั้งที่ซิงก์ (แท็บ `_data` ที่ซ่อนอยู่ ห้ามแก้หรือลบ)
- รูปสลิปอยู่ในโฟลเดอร์ **กระปุกเจี๊ยบ สลิป** ใน Google Drive
- ใช้หลายเครื่องได้: ใส่ลิงก์และรหัสลับเดียวกัน แล้วกด **ดึงข้อมูลจาก Sheet ทั้งหมด**
- ถ้าแก้โค้ด Apps Script ภายหลัง: Deploy → **Manage deployments** → ดินสอ → Version: **New version** → Deploy (ลิงก์เดิมไม่เปลี่ยน)
- ถ้ารหัสลับหลุด: เมนู 🐣 กระปุกเจี๊ยบ → **สร้างรหัสลับใหม่** แล้วใส่รหัสใหม่ในแอปทุกเครื่อง
